\begin{definition}[Common independent retention sample]
For a finite index set $I$ and $q\in[0,1]$, let
$\Omega=\{0,1\}^{I}$, with its discrete sigma algebra, and define
$\mu_q=\bigotimes_{i\in I}\operatorname{Bernoulli}(q)$.
Equivalently, the mass of $\omega$ is
$\prod_{i\in I}(q\text{ if }\omega_i=1,\;1-q\text{ otherwise})$.
The same sample $\omega$ is used for every retention test. For a graph on
$V$ we use $I=V\times V$; only coordinates oriented from $L$ to $R$
are used, so disjointness of $L,R$ assigns exactly one coordinate to
each undirected cross edge. Unused coordinates have no effect on the graph.
\end{definition}
