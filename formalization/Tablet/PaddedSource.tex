\begin{definition}
For a blow-up instance with source clusters $X_i$ and host clusters $V_i$, its padded source vertex set is
\[
 V(H)^+=V(H)\sqcup\coprod_{i\in[r]}[\,|V_i|-|X_i|\,].
\]
The second summand consists of dummy vertices, with exactly $|V_i|-|X_i|$ dummy vertices assigned to cluster $i$.  The difference is nonnegative by the capacity clause in \noderef{BlowUpInstance}.
\end{definition}
