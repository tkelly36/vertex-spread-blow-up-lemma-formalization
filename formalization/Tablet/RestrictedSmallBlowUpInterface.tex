\begin{lemma}[Exact restricted-instance interface]
Let $(H,G,R,(X_i),(V_i),(A^i))$ be a finite blow-up instance with candidacy graphs which is host-lower-$(\varepsilon,d)$-regular, and let $S\subseteq V(H)$.  Suppose $\Delta(H),\Delta(R)\leq\Delta$, $|S\cap X_i|\leq\varepsilon|V_i|$, $(1-\varepsilon)n\leq|V_i|\leq(1+\varepsilon)n$, and every $x\in S$ has at least $dn$ original candidates.  Restricting the source graph to $H[S]$ gives a blow-up instance on the subtype $S$ with the same host graph, reduced graph, host clusters, and candidacy relation.  Its source cluster is exactly $S\cap X_i$; more precisely, the subtype inclusion has image exactly $S$, its cluster map is the restriction of the original map, the host map is unchanged, and an allowed pair $(x,v)$ in the restricted system is exactly an original allowed pair.  The restricted instance is host-lower-$(\varepsilon,d)$-regular and satisfies all four quantitative premises needed to apply \noderef{PartialEmbedding}: both maximum-degree bounds, the small-source-fiber bound, the host-size window, and the $dn$ candidacy-degree bound.
\end{lemma}
\begin{proof}
Give the subtype $S$ the induced graph $H[S]$, restrict the source-cluster map, and retain the original host-cluster map.  The independence, capacity, and reduced-support clauses of \noderef{BlowUpInstance} give the following checks.  A source fiber is independent because its image lies in an original independent fiber.  Its cardinality is at most that of the original source fiber and hence at most the corresponding host fiber.  Every induced edge is an original edge, so the original reduced-support axiom supplies the required edge of $R$.  These observations verify every field of the restricted blow-up instance.

Define the restricted candidacy relation by $A_S(x,v)\iff A(x,v)$.  Cluster-respect follows from the cluster-respect clause of \noderef{CandidacySystem} for the original system and the equality of the restricted cluster maps.  The subtype inclusion plainly has image exactly $S$ (both inclusions follow respectively from subtype membership and from sending $x\in S$ to $\langle x,x\in S\rangle$), so no one-sided image assertion is being used.  The source-map, host-map, and candidacy equivalences hold by construction.  Host-lower-regularity only refers to $G$, $R$, and the host fibers, all of which are literally unchanged; unfolding \noderef{InstanceLowerRegular} therefore transports it.

It remains to check the numerical premises rather than silently identifying the large and small instances.  Passing to an induced subgraph cannot increase any vertex degree, so $\Delta(H[S])\leq\Delta(H)\leq\Delta$; the reduced graph is unchanged, giving its stated bound.  The exact-image equality identifies the $i$th source subtype fiber bijectively with $S\cap X_i$, so its cardinality has the assumed small-fiber bound.  The host map is unchanged, so the two host-size inequalities transfer verbatim.  Finally $A_S(x,v)\iff A(x,v)$ identifies, for each subtype vertex $x$, its candidate set with the original candidate set of its ambient image; the assumed $dn$ bound therefore transfers.  These are exactly the hypotheses listed in \noderef{PartialEmbedding}.
\end{proof}
