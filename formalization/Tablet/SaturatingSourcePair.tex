\begin{definition}
For a blow-up instance and two source clusters $X_i,X_j$, the bipartite source graph $H[X_i,X_j]$ is a \emph{saturating source pair} if it is a matching saturating the smaller side: either there is an injection $\tau:X_i\to X_j$ such that $xy\in E(H)$ exactly when $y=\tau(x)$, or there is an injection $\tau:X_j\to X_i$ such that $xy\in E(H)$ exactly when $x=\tau(y)$.  Thus the definition records both the matching property and that every vertex on at least one side is covered.
\end{definition}
