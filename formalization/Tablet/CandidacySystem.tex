\begin{definition}
For a blow-up instance \noderef{BlowUpInstance}, a system of candidacy graphs is a family of bipartite edge relations $A^i\subseteq X_i\times V_i$, one for each $i\in[r]$.  Equivalently, it is a single relation $A(x,v)$ such that $A(x,v)$ can hold only when $x\in X_i$ and $v\in V_i$ for the same index $i$; the edges with endpoints in $X_i,V_i$ form the candidacy graph $A^i$.
\end{definition}
