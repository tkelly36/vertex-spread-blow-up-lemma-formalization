\begin{definition}
Suppose the refined reduction data have $H\subseteq H'$, $G'\subseteq G$, candidacy containment $A'(x,v)\Rightarrow A(x,v)$, and exact projection of every refined source and host cluster to its original cluster.  For an $A'$-compatible embedding $\phi:H'\hookrightarrow G'$, define $\operatorname{restrict}(\phi)$ on every original residual source vertex by $\operatorname{restrict}(\phi)(x)=\phi(x)$.  This is a partial compatible embedding of $H$ on its full residual vertex set into $G$: injectivity is inherited from $\phi$, an edge of $H$ is an edge of $H'$ and its image edge in $G'$ remains an edge of $G$, and $A'$-compatibility implies $A$-compatibility.  The exact projection hypotheses identify the unions of the refined source and host parts with the original residual parts, rather than merely with subsets.  Consequently this construction is a total function on compatible refined embeddings and can be used directly as a pushforward map for a probability distribution.
\end{definition}
