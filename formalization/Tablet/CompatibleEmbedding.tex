\begin{definition}
Given a blow-up instance with candidacy graphs \noderef{CandidacySystem}, an injective graph homomorphism $\varphi:H\hookrightarrow G$ is \emph{compatible} if $x\varphi(x)$ is an edge of $A^i$ for every $i\in[r]$ and every $x\in X_i$. Here, as in the paper, an embedding preserves source edges but need not reflect host edges; in Mathlib this is a \texttt{SimpleGraph.Copy}, not an induced graph embedding.
\end{definition}
